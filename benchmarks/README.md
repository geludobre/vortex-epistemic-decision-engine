# Benchmarks

This directory is reserved for reproducible Vortex benchmark definitions and results.

A benchmark may be added only when it records dataset/source identity, time cutoffs, baseline identity, Vortex version, loss function, random seeds, environment, and raw result artifacts sufficient for independent reproduction.

Synthetic, replay, controlled, and retrospective benchmarks must be labeled explicitly and must never be counted as B1/B2 prospective evidence.

No benchmark result in this repository should be interpreted as universal superiority.
