# Licensing Decision Gate

**Status:** OPEN — no public license selected.

The repository is publicly visible, but public visibility is not an open-source license grant.

Until an explicit `LICENSE` file is approved and committed, downstream users should not infer permission to copy, modify, redistribute, sublicense, or commercialize the code beyond rights provided by applicable law.

## Decision required

Before adding `LICENSE`, the owner must explicitly decide:

- whether the public reference core is open source, source-available, or all-rights-reserved;
- which code, schemas, protocols, examples, and documentation are covered;
- whether enterprise connectors/integrations remain separately licensed;
- contributor and inbound-IP terms;
- patent treatment;
- trademark/name usage;
- compatibility with future commercial licensing.

## Repository boundary

A public-core license, if later selected, must not be interpreted as licensing private `vortex-enterprise`, customer evidence, private deployment configuration, enterprise connectors, or third-party material unless those assets explicitly say so.

## Change rule

Do not add a guessed MIT, Apache-2.0, GPL, or other license merely to complete repository structure.

The `LICENSE` file is created only after an explicit licensing decision.
